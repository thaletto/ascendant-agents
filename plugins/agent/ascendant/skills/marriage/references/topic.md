Required saved evidence: D1, D9, dasha, present yogas, SAV, and provenance.
Load transit positions only for a time-bound question.

For one-person readings, describe the saved person's relationship patterns and
timing. Another person's feelings require the compatibility rubric and both
saved charts.

For a two-chart marriage comparison, also apply the compatibility rubric's
bidirectional cross-chart overlay: locate each person's H7, H5, and H8 lords
in the other person's D1, recording the other-person house, sign, dignity, and
occupants, and repeat the overlay in D9. Treat these overlays as corroborating
evidence for the individual H7/H5/H8 judgments.
